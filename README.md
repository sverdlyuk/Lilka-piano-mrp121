## Потрібно

Лілка · плата MPR121 · 4 дроти «мама-мама» · 12 дротів із крокодилами ·
12 фруктів. Паяти нічого не треба, збирається за півгодини.

## 1. Лілка → плата

| Лілка | MPR121 |
|---|---|
| 3.3V | VCC |
| GND | GND |
| 47 | SDA |
| 48 | SCL |

Живлення тільки **3.3 В**. П'ять вольт уб'ють чіп.

## 2. Плата → фрукти

Дванадцять контактів `ELE0…ELE11`, до кожного крокодил із фруктом.
Ноти по порядку: `ELE0` — до, `ELE11` — сі.

## 3. Файли

`piano.lua` і `mpr121.lua` в **одну теку** на картці. Порізно не працює.

## 4. Запуск

**Спочатку причепи фрукти, потім запускай.**

При старті чіп запам'ятовує спокій. Фрукт, начеплений пізніше, звучатиме
безперервно — тоді прибери руки й натисни **A**.

## Керування

| | |
|---|---|
| **A** | перезняти базу |
| **▲ ▼** | октава |
| **◀ ▶** | чутливість |
| **B** | вихід |

Унизу екрана «тримаєш: 0» — скільки клавіш чіп бачить зараз. У спокої має
бути нуль.

## Якщо не працює

| Симптом | Що робити |
|---|---|
| Нота лунає сама | прибрати руки, натиснути **A** |
| «MPR121 не відповідає» | перевірити SDA/SCL і 3.3 В, натиснути **A** |
| Спрацьовує сусідня клавіша | **▶** — менш чутливо |
| Клавіша мовчить | **◀** — чутливіше; перевірити крокодил |
| Червоне «СТРУМ!» | коротке замикання, вимкнути й перевірити дроти |
| Дуже тихо | так і має бути, зумер малий; постав на стіл |

## Змінити

На початку `piano.lua`:

```lua
mpr121.new(47, 48, { touch = 30 })   -- SDA, SCL, чутливість
local OCTAVE = 4                     -- октава при запуску
```

`touch = 30` підібрано під фрукти, для голого пальця краще 12–15.
Більше число — менш чутливо.

## Як це працює

Не провідність, а **ємність**. Чіп заряджає й розряджає клавішу і рахує,
скільки заряду вона бере. Палець торкнувся — ємність стрибнула.

Тому дотик ловиться навіть крізь скотч чи папір. І тому працює олівець:
графіт проводить, треба лише заштрихувати щільно, доки папір не блищить.

## mpr121.lua

Самостійна бібліотека, можна брати у свої проєкти:

```lua
local mpr121 = require("mpr121")
local touch  = mpr121.new(47, 48)
touch:begin()
if touch:down(0) then ... end
```

Уміє більше: пороги, автоналаштування, режим наближення, сторож проти
залипання. Опис — у коментарях на початку файлу.
